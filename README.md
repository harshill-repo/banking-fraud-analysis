# Banking Risk and Fraud Analytics Dashboard
**Tools Used:** SQL (MySQL), Power BI, Power Query
**Dataset:** 600,000+ retail banking transactions

### Project Overview
Built an end-to-end data pipeline and interactive dashboard to detect high-value transaction anomalies and track fraud rates across merchant categories.

### Key Features
* **Data Engineering:** Ingested and cleaned 600k+ rows using SQL and Power Query, bypassing local memory bottlenecks.
* **Exploratory Analysis:** Designed SQL views and queries to identify spending spikes and establish baseline fraud metrics.
* **Data Visualization:** Engineered an interactive Power BI dashboard utilizing custom DAX measures, KPI tracking, and dynamic slicers for merchant-level drill-downs.
